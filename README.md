# PsiRizerio - Portal do Paciente (Mobile)

Este repositório contém a aplicação mobile da clínica **PsiRizerio**, desenvolvida como projeto do último semestre. O aplicativo serve como um portal dedicado para pacientes, facilitando a gestão de consultas e o acompanhamento do progresso terapêutico.

## 🛠️ Tecnologias Utilizadas

- [**React Native**](https://reactnative.dev/) - Framework para desenvolvimento mobile.
- [**Expo**](https://expo.dev/) - Plataforma e ecossistema para desenvolvimento universal com React.
- [**Expo Router**](https://docs.expo.dev/router/introduction/) - Navegação baseada em arquivos.
- [**TypeScript**](https://www.typescriptlang.org/) - Adição de tipagem estática para maior segurança no código.
- [**React Native Reanimated**](https://docs.swmansion.com/react-native-reanimated/) - Biblioteca para animações fluidas e de alto desempenho.

## 📂 Estrutura do Projeto

O código fonte principal está localizado no diretório [`psiRizerio-mobile`](./psiRizerio-mobile).

```text
psiRizerio-mobile/
├── app/             # Rotas e telas da aplicação (Expo Router)
├── assets/          # Imagens, ícones e fontes
├── components/      # Componentes UI reutilizáveis
├── constants/       # Configurações de tema e constantes globais
├── hooks/           # Hooks personalizados
└── scripts/         # Scripts auxiliares de desenvolvimento
```

## 🏁 Como Começar

Para rodar o projeto localmente, siga as instruções detalhadas no [**README específico do aplicativo**](./psiRizerio-mobile/README.md).

Em resumo:

1. Entre na pasta `psiRizerio-mobile`.
2. Instale as dependências: `npm install`.
3. Inicie o projeto: `npx expo start`.
